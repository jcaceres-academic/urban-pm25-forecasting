Scripts and Analytical Workflow

Original computational structure of the AppliedMath 2024 study

🎯 Purpose

This page documents the original Python scripts and their role in the analytical workflow.

It intentionally contains no result figures. Analytical outputs are shown on the project home and in the analytical notebook.

🗂️ Script inventory

Script Main role
01_data_preprocessing.py Clean, transform and prepare PM2.5 observations
02_spatial_analysis.py Analyse spatial variation in PM2.5
03_descriptive_analysis.py Produce descriptive statistics and temporal summaries
04_trends_by_district.py Analyse temporal trends by district
05_districts_pm25_map.py Generate district-level PM2.5 maps
06_stations_map.py Generate the monitoring-station map
07_hybrid_forecasting.py Implement citywide Prophet-LSTM forecasting
08_district_forecasting.py Extend Prophet-LSTM forecasting to individual districts

🔄 Execution logic

The analytical workflow can be summarised as:

scripts/data/
     ↓
01_data_preprocessing.py
     ↓
├── 02_spatial_analysis.py
├── 03_descriptive_analysis.py
└── 04_trends_by_district.py
     ↓
├── 05_districts_pm25_map.py
└── 06_stations_map.py
     ↓
07_hybrid_forecasting.py
     ↓
08_district_forecasting.py

The scripts are organised by analytical stage rather than by the order in which figures appear in the article.

🧩 Workflow by stage

Data preparation

01_data_preprocessing.py creates the analysis-ready PM2.5 data structures used by the downstream scripts.

Descriptive and temporal analysis

03_descriptive_analysis.py and 04_trends_by_district.py generate the statistical and temporal summaries used to characterise PM2.5 evolution.

Spatial analysis

02_spatial_analysis.py, 05_districts_pm25_map.py and 06_stations_map.py support spatial interpretation and monitoring-network visualisation.

Forecasting

07_hybrid_forecasting.py implements the citywide Prophet-LSTM workflow.

08_district_forecasting.py applies the forecasting framework at district level.
